# Waze Profile UserID
 
![Repo](https://img.shields.io/badge/Repo-Public-blue)
![Language](https://img.shields.io/badge/Language-JavaScript-yellow)
[![Requires Tampermonkey](https://img.shields.io/badge/Requires-Tampermonkey-orange?logo=tampermonkey&logoColor=white)](https://www.tampermonkey.net/)
![License](https://img.shields.io/badge/License-MIT-lightgrey)
 
Zeigt beim Aufrufen eines Waze Editorprofils die eindeutige User-ID an. Durch Klick auf das Feld wird sie kopiert.
 
## Installation
 
1. [Tampermonkey](https://www.tampermonkey.net/) installieren (Chrome, Firefox, Edge, Safari...)
2. [`waze-profile-userid.user.js`](./waze-profile-userid.user.js) öffnen bzw. manuell in Tampermonkey einfügen
 
## Nutzung
 
- Im [Waze Map Editor (WME)](https://waze.com/editor) einloggen
- Waze Editorenprofil aufrufen, User-ID wird angezeigt
